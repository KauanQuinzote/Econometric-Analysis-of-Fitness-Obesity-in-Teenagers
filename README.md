# Econometric-Analysis-of-Fitness-Obesity-in-Teenagers
Fitness Infrastructure and Obesity Trends: A Comparative Econometric Analysis of São Paulo's Youth (2018 vs. 2023)

This project investigates the relationship between the availability of fitness centers and obesity rates among the Generation Z population in the state of São Paulo, Brazil.

Using a comparative cross-sectional design, this study examines how the density of fitness facilities per capita correlates with public health indicators, comparing pre-pandemic (2018) and post-pandemic (2023) datasets. By controlling for socio-economic variables such as average household income, education levels, and population density, the analysis aims to isolate the impact of sports infrastructure on obesity outcomes.
